USAGE
The guide is the current reference. The original concept board includes
an earlier tagline which has been dropped; do not reuse that tagline.
Use Beacon in normal prose and the supplied lowercase wordmark as artwork.
PNG files are the original generated assets, preserved without modification.
They are raster images, not vector masters. Inspect edges and appearance at
the intended size before shipping. No SVG, ICNS or Xcode asset catalogue is
included. For a native menu bar icon, import the monochrome symbol as a
template image and check its silhouette at the actual rendered size.
SF Pro and SF Mono are the intended app typefaces; fonts are not bundled.
The guide uses macOS system fonts. Colour values in the palette files are
authoritative; generated imagery may contain slight colour variation.
